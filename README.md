Entrants name the one word they would erase from the dictionary forever, and a judge model compares picks head to head until the funniest deletion wins.

This entry deletes **goodbye**: erase it and nobody can ever say goodbye again — every farewell becomes an awkward hover, every phone call ends in "...so... yeah" and silence. The word *is* the ritual of leaving, so deleting it deletes clean exits everywhere. One word, spelled correctly, nothing added.

## Run it

```sh
python3 main.py
```

Writes exactly one word to `/output/entry.txt` (7 bytes, no trailing newline), deterministically, exit 0.
